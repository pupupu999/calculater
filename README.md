# アプリ名 Chipin
## アプリの概要
このアプリはお金を賭けずにポーカーを楽しむことをモットーに友人とのライブポーカーの成績を管理するアプリです。部屋を作成もしくは参加し、
ゲーム終了時の手元のチップ量を入力することで、全員の収支をリアルタイムで反映し結果が正しいかの確認ができます。
戦績推移の折れ線グラフ表示や、過去の対戦結果をソートできるテーブル機能や全ユーザーの通算収支のランキング機能を備えています。

## ローカル環境での実行方法

### 1. ローカルIPアドレスを確認
まず、MacのローカルIPアドレスを確認します。
```bash
ifconfig | grep "inet " | grep -v 127.0.0.1
```
または
```bash
ipconfig getifaddr en0
```

表示されたIPアドレス（例：`192.168.0.50`）をメモしておきます。

### 2. サーバーとクライアントを起動
プロジェクトのルートディレクトリで以下を実行します：
```bash
npm run start-all
```

これにより：
- サーバーがポート3001で起動
- クライアントがポート3000で起動

### 3. ブラウザからアクセス
**パソコンからアクセスする場合：**
- `http://localhost:3000` にアクセス

**スマートフォンからアクセスする場合：**
1. パソコンとスマートフォンが同じWi-Fiネットワークに接続されていることを確認
2. スマートフォンのブラウザで `http://[あなたのローカルIPアドレス]:3000` にアクセス
   - 例：`http://192.168.0.50:3000`

### 重要な注意事項
- 開発環境では、ローカルネットワークIPアドレス（192.168.x.x、10.x.x.x、172.16-31.x.x）からのアクセスが自動的に許可されるように設定されています
- 本番環境（Render.com）にデプロイする際は、`server/server.js`のCORS設定を適切に調整してください
